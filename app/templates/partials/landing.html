Research basis

Logic before pixels.

01

Six inputs

RBC, Hb, MCV, MCH, MCHC, dan RDW-CV diproses mengikuti urutan fitur model yang dibekukan.

02

Fixed threshold

Keputusan model menggunakan threshold penelitian 0.91, bukan ambang diagnosis klinis.

03

No storage

MVP tidak menyimpan identitas, input hematologi, maupun riwayat hasil ke database.

About HemaLens

A restrained interface for model transparency.

Antarmuka dibangun dengan FastAPI, Jinja2, HTMX, Alpine.js, dan Tailwind CSS. Lapisan visual Three.js ditambahkan setelah alur inference dasar stabil.
