- Modular FastAPI project.
- Lifespan-based artifact loading.
- SHA-256 artifact integrity verification.
- Model version and feature-order validation.

- Internal prediction endpoint.
- Health endpoint.
- Privacy-safe logging baseline.
- Automated tests.
- Docker and VS Code configuration.
